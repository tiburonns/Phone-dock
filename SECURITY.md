# Security policy

## Supported versions

Only the latest release is supported with security fixes. Phone Dock protocol v2 encrypts authenticated traffic and rejects stale or replayed messages. Protocol v1 peers are intentionally incompatible and should be upgraded together.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting or a private security advisory for this repository. Do not include pairing credentials, device names, local addresses, or captured traffic in a public issue.

Reports should include the affected platform and version, reproduction steps, expected impact, and any suggested mitigation. You can expect an acknowledgement before public disclosure is coordinated.
