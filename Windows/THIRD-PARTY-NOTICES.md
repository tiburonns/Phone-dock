# Dependencias de Phone Dock para Windows

Este paquete incorpora el runtime redistribuible .NET y bibliotecas NuGet. Se conservan los avisos del runtime en la distribución. Las licencias de las dependencias son independientes del código de Phone Dock.

- .NET / WPF y bibliotecas System.* — Microsoft y colaboradores, licencia MIT. [Licencia y avisos del runtime](https://github.com/dotnet/runtime/blob/main/LICENSE.TXT), [WPF](https://github.com/dotnet/wpf/blob/main/LICENSE.TXT).
- NAudio.Wasapi / NAudio.Core — Mark Heath y colaboradores, licencia MIT. [Repositorio y licencia](https://github.com/naudio/NAudio).
- Makaretu.Dns.Multicast y dependencias resueltas — [proyecto net-mdns](https://github.com/richardschneider/net-mdns). Las licencias de los paquetes se incluyen en `licenses/` en la distribución.

Las versiones exactas, incluidas las dependencias transitivas, se registran en `PhoneDock/packages.lock.json`.
