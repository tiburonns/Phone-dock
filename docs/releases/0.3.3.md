# Phone Dock 0.3.3

- Automatically reconnects remembered Macs with bounded exponential backoff.
- Shows connection, protocol, retry, error, and key-rotation diagnostics on iPhone.
- Reports explicit protocol-version mismatches.
- Rotates pairing secrets without requiring manual re-pairing.
- Keeps the previous secret only until the client confirms the replacement, and uses it to recover an interrupted rotation.
- Includes the protocol v2 encryption, replay protection, privacy manifest, and cross-platform CI introduced in the preceding hardening work.
