# Phone Dock 0.3.2

**English · [Español](0.3.2.md)**

- **Long-press new instance:** hold an application tile for 0.6 seconds to request another instance on Mac or Windows; normal taps keep switching to an existing window.
- **iPhone sliders:** periodic refresh no longer overwrites values during interaction; changes are debounced and the final value is sent on release.
- **Windows volume:** controls the default output device, verifies applied values, and unmutes when volume is raised.
- **Windows brightness:** uses WMI for integrated displays or DDC/CI for the primary external monitor when supported by monitor/driver/connection.
- Existing language, appearance, palette, and customization behavior remains intact.
