# Phone Dock 0.3.3

**[English](0.3.3.md) · Español**

- Reconexión automática de Macs recordadas con backoff exponencial acotado.
- Diagnósticos de conexión, protocolo, reintentos, errores y rotación de claves en iPhone.
- Errores explícitos ante versiones de protocolo incompatibles.
- Rotación de secretos de pairing sin exigir emparejar manualmente de nuevo.
- Conservación temporal del secreto anterior hasta confirmar el reemplazo para poder recuperar una rotación interrumpida.
- Incluye cifrado del protocolo v2, protección contra replay, privacy manifest y CI multiplataforma introducidos durante el hardening previo.
