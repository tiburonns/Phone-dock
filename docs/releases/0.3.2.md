# Phone Dock 0.3.2

## Novedades y correcciones

- **Nueva instancia con pulsación larga:** mantén pulsado un icono de aplicación en el iPhone durante 0,6 segundos para solicitar otra instancia en Mac o Windows. El toque corto conserva el cambio a una ventana existente. Las aplicaciones que solo admiten una instancia pueden reutilizar su ventana o rechazar la solicitud. Las acciones de webs, texto y atajos no cambian. En Recientes de Mac, fijar/desfijar ahora tiene su propio botón.
- **Sliders de iPhone:** el refresco periódico ya no sobrescribe el valor mientras arrastras. Se envían cambios con una pausa breve durante el gesto y el valor final al soltar.
- **Volumen Windows:** se utiliza la salida predeterminada de audio, se verifica el valor aplicado y subir el volumen desactiva el silencio. Los cambios de dispositivo de salida se detectan en cada solicitud.
- **Brillo Windows:** detección de pantalla integrada mediante WMI o, si no hay una integrada disponible, del monitor principal mediante DDC/CI. Hace falta soporte del monitor, controlador y conexión; algunos monitores requieren activar DDC/CI en su menú físico. Sin soporte detectable, el control queda deshabilitado. No hay selector de pantalla: si están conectadas una integrada y una externa, se prioriza la integrada.
- **Nuevo DMG universal para Mac**, compatible con Intel y Apple Silicon.

Actualiza **el iPhone y la app compañera del ordenador** para usar estas funciones. Se conservan los ajustes y los emparejamientos.

## Descargas

- **Mac:** `PhoneDock-0.3.2-universal.dmg`. macOS 14 o posterior. Cierra la app anterior, abre el DMG y arrastra Phone Dock a Applications. Incluye instrucciones en Español y English. Tiene firma ad hoc, **no Developer ID ni notarización de Apple**; macOS puede bloquear su apertura. Verifica la procedencia y SHA-256 y, solo si confías en esta copia, autoriza esa app en Privacidad y seguridad → Abrir igualmente. No desactives Gatekeeper. Para una distribución notarizada hace falta un certificado Developer ID que no está disponible en este entorno.
- **Windows:** `PhoneDock-Windows-x64.zip`. Windows 11 x64, incluye .NET. Cierra la app anterior y descomprime toda la nueva carpeta. El ejecutable de prueba no está firmado con certificado de distribución; no desactives las protecciones de Windows.
- **iPhone/iPad:** `PhoneDock-0.3.2.ipa`, iOS/iPadOS 17 o posterior. IPA Release sin certificados ni perfiles personales para que AltStore Classic lo firme con tu cuenta. No es para AltStore PAL ni App Store.

Fuente estable para **AltStore Classic → Browse → Sources → +**:

```text
https://raw.githubusercontent.com/tiburonns/Phone-dock/main/altstore/source.json
```

El archivo `source.json` también se adjunta a esta publicación. `SHA256SUMS-0.3.2.txt` permite verificar las descargas.

## Clonar en Xcode

En **Clone Git Repository**, pega `https://github.com/tiburonns/Phone-dock.git` y abre `PhoneDock.xcodeproj`. Usa `PhoneDockMobile` o `PhoneDockMac`. No necesitas XcodeGen. Para instalar desde Xcode en un iPhone físico, selecciona tu propia cuenta en Signing & Capabilities.
