# Phone Dock 0.3.1

## Correcciones

- iPhone: la zona «Swipe to control» queda fija al pie de Controles, fuera del área desplazable. Deslizar ahí ya no desplaza los controles; el resto de la pantalla sigue permitiendo scroll. Incluye acciones accesibles para los cuatro gestos.
- Windows: al seleccionar una app se busca su ventana abierta y se intenta traerla al frente. Las ventanas minimizadas se restauran. Si Windows bloquea el foco, no se lanza otra instancia. También se evitan aperturas repetidas durante 15 segundos mientras una app arranca.
- Se mantienen Español, English, selección automática del idioma, paletas y personalización.

## iPhone / iPad · AltStore Classic

Descarga `PhoneDock-0.3.1.ipa` o agrega esta fuente en **Browse → Sources → +**:

```text
https://raw.githubusercontent.com/tiburonns/Phone-dock/main/altstore/source.json
```

También se adjunta `source.json` a esta publicación. Usa la dirección anterior para recibir futuras actualizaciones de la fuente.

Requiere iOS/iPadOS 17 o posterior y AltStore Classic configurado con AltServer. El IPA es una compilación Release sin certificados ni perfiles personales; AltStore lo vuelve a firmar con tu cuenta. No es para AltStore PAL ni App Store. Necesita la aplicación compañera de Mac o Windows en la misma red local.

## Windows

Descarga `PhoneDock-Windows-x64.zip`, cierra la app anterior y descomprime toda la carpeta nueva. Abre `PhoneDock.exe`; tus ajustes se conservan en la carpeta local de Phone Dock. Windows 11 x64, sin necesidad de instalar .NET. El ejecutable de prueba no tiene firma de distribución; no desactives las protecciones de Windows.

## Clonar en Xcode

En **Clone Git Repository**, pega `https://github.com/tiburonns/Phone-dock.git` y abre `PhoneDock.xcodeproj`. Los esquemas `PhoneDockMobile` y `PhoneDockMac` ya están incluidos. No necesitas XcodeGen. Para un iPhone físico, selecciona tu propia cuenta en Signing & Capabilities; el repositorio no configura una cuenta personal.

## Verificación y límites

Se comprueban la compilación de iOS y Windows, las pruebas de direcciones de gestos y del control de activación, y la concordancia del IPA con su fuente (versión, tamaño, plataforma y permisos). La instalación final con AltStore y el comportamiento de foco de Windows requieren prueba en los dispositivos reales. No se modificaron las aplicaciones ya instaladas en tus dispositivos durante esta publicación.
