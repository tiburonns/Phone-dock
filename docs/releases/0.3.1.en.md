# Phone Dock 0.3.1

**English · [Español](0.3.1.md)**

## Fixes

- iPhone: the “Swipe to control” area stays pinned below the scrollable controls so control gestures no longer scroll the page. Accessibility actions are provided for all four gestures.
- Windows: selecting an app first searches for an existing window, restores minimized windows, and avoids launching duplicate instances when focus is blocked. Repeated launch taps are suppressed during startup.
- English, Spanish, system-language selection, palettes, and customization remain supported.

## AltStore Classic

Download `PhoneDock-0.3.1.ipa` or add the repository AltStore source. The IPA is unsigned for redistribution and is re-signed by AltStore with the user's account. A Mac or Windows companion on the same local network is required.
