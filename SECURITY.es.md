# Política de seguridad

**[English](SECURITY.md) · Español**

Sólo la versión/revisión más reciente recibe correcciones de seguridad.

El protocolo v3 utiliza identidad estable de cliente y host, cifrado autenticado, protección contra replay y rotación/revocación de credenciales. Peers con versiones de protocolo incompatibles deben actualizarse juntos.

Para reportar una vulnerabilidad usa el sistema privado de GitHub (Private vulnerability reporting / Security advisory). No publiques credenciales de pairing, nombres de dispositivos, direcciones locales ni capturas de tráfico.

Incluye plataforma/versión, pasos mínimos para reproducir, impacto esperado y mitigación sugerida.
