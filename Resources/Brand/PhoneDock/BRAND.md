# Phone Dock — Aurora identity

Created with the built-in image generation tool (not the API/CLI fallback).

## Deliverables

- AppIcon-Source.png: master square mark, shared by Mac and iPhone.
- Wordmark.png: previous horizontal wordmark retained as a legacy asset; the app icon is the current identity.
- The previous CocoaLift-AppIcon-Source.png remains in the parent folder as an archive.

The app icon exports are generated by script/generate_app_icons.swift. iOS uses an opaque square; macOS uses a rounded mask and transparent exterior margin. The in-app BrandIcon image is kept in both asset catalogs. UI text stays native for accessibility and light/dark contrast.

## Prompts

### Final app icon
Use case: logo-brand. Asset type: production square app icon for Phone Dock. Reconstruct the approved reference as a standalone icon: a front-facing Mac display clearly visible in the background, with an upright coral-red iPhone seated in a rounded purple dock in the foreground, two aqua wireless arcs to the right, and a small cyan status light in the base. Use polished geometric gradients and a centered layered composition on a full-bleed opaque deep-navy background. The Mac stays secondary but readable. No text, wordmark, card, border, transparent corners, watermark, or outer rounded-square mask; the operating system supplies the final icon mask. 1024 by 1024.
